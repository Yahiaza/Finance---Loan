# الإدارة المالية — V5.2 Performance

هذه النسخة مخصصة لتقليل وقت الـ Build وتسريع تشغيل النسخة المحمولة.

## التشغيل أثناء التطوير
شغّل `START_DEV.bat` أو:

```bash
npm run dev
```

لا تعمل Portable بعد كل تعديل. استخدم وضع التطوير، واعمل Build فقط عند الانتهاء.

## أسرع نسخة Portable (موصى بها)
شغّل:

`BUILD_PORTABLE.bat`

أو:

```bash
npm run portable:folder
```

ستجد البرنامج داخل `release\win-unpacked\`. هذا مجلد Portable حقيقي: لا يحتاج تثبيت ولا صلاحيات Admin. يجب نقل المجلد كاملًا معًا. هذه النسخة تفتح أسرع لأنها لا تفك ضغط Electron في TEMP في كل تشغيل.

## ملف Portable EXE واحد
شغّل:

`BUILD_SINGLE_EXE.bat`

أو:

```bash
npm run portable:exe
```

سيظهر `Financial-Reports-Portable-1.4.0.exe` داخل `release`. ملف EXE الواحد أبطأ في البداية بطبيعته لأنه Self-Extracting Portable.

## ما تم تحسينه
- كل React/Vite/Lucide/Cairo أصبحت devDependencies فقط؛ الـ renderer مبني بالفعل داخل dist ولا نكرر node_modules داخل التطبيق.
- ASAR مفعّل.
- compression = store لتقليل وقت بناء الـ Portable.
- npmRebuild = false لأنه لا توجد Native Node modules في المشروع.
- الاحتفاظ بلغة Electron en-US فقط لتقليل ملفات locales غير المستخدمة.
- تصغير صورة الأيقونة المستخدمة داخل الواجهة إلى 96px.
- نافذة Electron لا تظهر بيضاء أثناء تحميل React؛ تظهر عند ready-to-show.
- BUILD_PORTABLE.bat أصبح يبني win-unpacked السريع افتراضيًا.
- BUILD_UI_ONLY.bat لبناء Vite فقط عند الحاجة.

## ملاحظة مهمة
`npm install` يحدث مرة واحدة فقط طالما مجلد `node_modules` موجود. لا تحذفه بين كل Build.

## الإصدار 1.5.0 — قسم القروض
- قسم جديد في الشريط الجانبي باسم **القروض > تسجيل القروض**.
- إنشاء قرض باسم القرض وعدد الأقساط، مع إنشاء صفوف الأقساط تلقائيًا.
- إمكانية زيادة عدد الأقساط لاحقًا بزر **إضافة قسط**.
- أعمدة القرض: م، تاريخ الاستحقاق، قسط القرض مع الفوائد، قسط القرض، المسدد من القرض، العمولة، المسدد من العمولة، الإجمالي، النفقات الإيرادية المؤجلة.
- المبالغ بتنسيق آلاف أثناء الإدخال، والتاريخ بأسلوب يوم / شهر / سنة.
- إحصائية تلقائية: إجمالي القرض، إجمالي العمولة، المسدد من القرض، المسدد من العمولة، الباقي من القرض، الباقي من العمولة.
- بيانات القروض تدخل تلقائيًا ضمن تصدير JSON الكامل.
- تمت إضافة أوامر موحدة للبناء: `npm run build:portable` و `npm run build:folder`.

## إصلاح V6.1 للبناء Portable

الأمر القياسي الآن:

```bash
npm run build:portable
```

تم إصلاح سكربت البناء ليستخدم إعداد `win.target = portable` الموجود داخل `package.json` مباشرة،
بدلاً من تمرير `portable` بعد `--x64` في سطر الأوامر، والذي كان يسبب:
`Unknown argument: portable`

كما تم تغيير `vite.config.js` إلى `vite.config.mjs` لإزالة تحذير ESM/CommonJS في Vite 8.

لنسخة المجلد السريعة:
```bash
npm run build:folder
```

## تحديث V6.2 — القروض وExcel

تم تغيير جدول القروض إلى:

م | تاريخ الاستحقاق | قسط القرض | العمولات البنكية | قسط البنك مع العمولات البنكية | المسدد | الفرق | العمولات عن كل سنة

- قسط البنك مع العمولات = قسط القرض + العمولات البنكية تلقائيًا.
- الفرق = قسط البنك مع العمولات - المسدد تلقائيًا.
- العمولات السنوية تُجمع حسب سنة تاريخ الاستحقاق وتظهر في قسط ديسمبر. إذا لم يوجد ديسمبر، تظهر في آخر قسط للسنة.
- زر استيراد Excel يقرأ XLSX/XLS ثم يطلب ربط أعمدة الملف بخانات البرنامج قبل الاستيراد.
- الأمر المعتاد لإنشاء Portable EXE:

```bash
npm install
npm run build:portable
```

## V6.4.1 - تصحيح إحصائية القرض

- إجمالي القرض بدون فوائد = مجموع عمود قسط القرض فقط.
- إجمالي الفوائد = مجموع العمولات البنكية فقط.
- الإجمالي العام = إجمالي القرض بدون فوائد + إجمالي الفوائد.
- الباقي من القرض = الإجمالي العام - المسدد.


## V6.4.2 - تصحيح الباقي من القرض

الباقي من القرض = الإجمالي العام (قسط القرض + الفوائد) - إجمالي المسدد.
